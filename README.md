
# 🐍 Java Snake Game – DSA Project

A classic Snake Game developed using **Java**, applying Data Structures and Algorithms (DSA) concepts. The project demonstrates how LinkedList can be used to manage snake movement, growth, and body segments.

## 📌 Project Overview

The player controls a snake using the arrow keys. The objective is to collect food, increase the score, and grow the snake without colliding with the walls or its own body.

## 🚀 Features

- Snake movement in four directions.
- Food generation at random positions.
- Score increases by 10 points after eating food.
- Snake grows after collecting food.
- Wall collision detection.
- Self-collision detection.
- Pause and resume functionality.
- Restart functionality.
- High-score tracking.

## 🛠️ Technologies Used

- Java
- Java Swing
- Java AWT
- Data Structures and Algorithms
- LinkedList

## 🧠 DSA Concepts Implemented

**LinkedList:** Stores the positions of the snake's body.

**Insertion:** `addFirst()` adds a new head position.

**Deletion:** `removeLast()` removes the tail when food is not eaten.

**Traversal:** Used to draw the snake and check collisions.

**Searching:** Used to check whether a position is occupied by the snake.

## 🎮 Controls

| Key | Function |
|---|---|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| P | Pause / Resume |
| R | Restart after Game Over |

## ⚙️ How to Run

1. Install Java JDK.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Compile the Java files:

```bash
javac Snake.java GamePanel.java SnakeGame.java
```

6. Run the game:

```bash
java SnakeGame
```
